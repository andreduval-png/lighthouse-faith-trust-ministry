# Lighthouse Faith & Trust Ministry

Public website for Lighthouse Faith & Trust Ministry, built with React, TypeScript, Vite, React Router, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Vercel Deployment

- Framework preset: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`
